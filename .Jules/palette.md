## 2024-05-18 - Submit Form Accessibility\n**Learning:** When using loading states or error messages in forms, dynamic DOM insertions should use `role="alert"` (for assertive/critical errors) and `role="status"` (for polite success messages). Custom progress tracks built with `div` should act like native progress elements by specifying `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` attributes, while accompanying descriptive text should have `aria-hidden="true"` to prevent redundant screen reader announcements.\n**Action:** Use these specific ARIA attributes for custom form alert and loading/progress UI components.
