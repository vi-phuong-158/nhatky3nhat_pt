## 2024-05-18 - Remove Static aria-labels and Support Dynamic Button Text / Progress Bar
**Learning:** Static `aria-label`s on buttons (e.g. `aria-label="Gửi lưu bút"`) override the dynamically updated inner text content of the button (like "Đang tải file..." or "Đang xử lý..."). Consequently, screen readers announce the static text instead of the true button status, leaving users unaware of the loading state. Moreover, custom `<div>`-based progress bars lack native semantic meaning to assistive technologies unless explicitly marked up with `role="progressbar"` and progress range/value `aria-*` attributes.
**Action:** Do not place static `aria-label`s on buttons that contain dynamic text content reflecting form submission or loading status. When building custom visual progress indicators, ensure they have the proper `progressbar` roles and value attributes (`aria-valuenow`, `aria-valuemin`, `aria-valuemax`), and hide redundant helper text (`aria-hidden="true"`) to prevent double-announcing.
