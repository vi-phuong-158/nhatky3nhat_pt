## 2024-06-09 - Adding Keyboard Accessibility to Custom Modals
**Learning:** In React applications utilizing Framer Motion or custom div overlays for modals, developers often forget to bind the `Escape` key to the closing functionality. While they might implement click-outside behaviors or close buttons, the absence of `Escape` key dismissal is a critical accessibility failure for keyboard users. Furthermore, missing `role="dialog"`, `aria-modal="true"`, and `aria-labelledby` causes screen readers to misinterpret the new interactive context.
**Action:** When creating or reviewing custom modal components, always verify that an `Escape` key event listener is bound (e.g. via `useEffect` tracking the `keydown` event), and that the root container has `role="dialog"`, `aria-modal="true"`, and an `aria-labelledby` attribute pointing to the modal's title ID.
