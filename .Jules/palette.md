## 2024-06-07 - Progress Bar and Decorative Icons Accessibility
**Learning:** In custom progress indicators (like a file upload progress bar built with `div`s), setting `role="progressbar"` along with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` is crucial so screen readers can interpret dynamic progress accurately. Also, decorative icons such as Google Material Symbols (`span.material-symbols-outlined`) often lack native semantic meaning. To prevent screen readers from reading meaningless textual ligatures (e.g., "close", "error"), `aria-hidden="true"` should always be applied.
**Action:** Always add `role="progressbar"` and related dynamic `aria-value` attributes to custom load/progress bars. Apply `aria-hidden="true"` to any decorative icon components, ensuring interactive elements have a separate descriptive `aria-label`.
