## 2024-10-25 - Interactive Div Accessibility
**Learning:** In a heavily customized React UI like `PostCard.jsx` where `div` or `img` tags act as buttons (e.g., clicking an image to open a lightbox), these elements strictly require `role="button"`, `tabIndex={0}`, `aria-label`, and crucially, an `onKeyDown` listener. React's `onClick` does not automatically capture 'Enter' or 'Space' keypresses for non-button elements, which breaks keyboard navigation. Furthermore, pressing 'Space' on an interactive element by default causes the browser window to scroll down.
**Action:** When converting non-interactive elements into clickable targets, ensure a robust `onKeyDown` handler is implemented that not only triggers the callback on 'Enter' and 'Space' but also calls `e.preventDefault()` specifically for 'Space' to prevent unwanted page scrolling.
