## $(date +%Y-%m-%d) - Enhance form accessibility in SubmitForm
**Learning:** Decorative icons (like material symbols) inside form labels/inputs and interactive elements need explicit `aria-hidden="true"` to prevent screen readers from reading the icon font names, which creates noise. Notifications and dynamically rendered messages require appropriate ARIA roles (`role="alert"` for errors, `role="status"` for success) to ensure they are announced correctly and immediately to assistive tech. Furthermore, `required` HTML attributes should be paired with `aria-required="true"` to enforce native browser validation consistently and provide strong semantic context.
**Action:** Always verify if visual feedback/icons have appropriate ARIA semantics applied and if native HTML validation attributes are used to build inherently accessible forms.
