## 2024-05-18 - Native Form Validation for Screen Readers\n**Learning:** Relying solely on JS validation for forms misses the opportunity to utilize native browser accessibility features like `required` and `aria-required`, which provide immediate, robust feedback to assistive technologies before the submit event fires.\n**Action:** Always add native HTML5 validation attributes (`required`) along with `aria-required="true"` to mandatory form inputs, and ensure dynamic validation error/success messages use `role="alert"` or `role="status"`.
