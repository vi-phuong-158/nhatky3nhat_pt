## 2024-05-27 - Enhance Form Accessibility and Validation
**Learning:** React state-driven form validation in `SubmitForm.jsx` correctly prevented invalid data flow to the backend but lacked robust client-side ARIA hints for screen readers and skipped native HTML5 validation capabilities. Specifically, decorative Material Symbols icons (`sf-input-icon`, etc.) could disrupt screen-reader context if not explicitly hidden with `aria-hidden="true"`, and the form state messages lacked `role="alert"` and `role="status"`.
**Action:** Always ensure that visually mandatory form fields (marked with `*`) use native `required` and `aria-required="true"` properties, add semantic ARIA roles to dynamic state containers (e.g. `role="alert"` for errors and `role="status"` for success messages), and hide decorative icon wrappers using `aria-hidden="true"`.
