## 2026-06-22 - Adding Dialog Semantics to Framer Motion Overlays
**Learning:** When building custom overlays or modals using libraries like Framer Motion, it's critical to manually implement accessibility features. Interactive overlay components must include `role="dialog"` and `aria-modal="true"` to appropriately inform screen readers that they are interacting with a modal dialog. Also, implementing a centralized listener for the 'Escape' key ensures robust dismissal functionality, aligning with UX standards for modals.
**Action:** Always include `role="dialog"`, `aria-modal="true"`, and a descriptive `aria-label` (or `aria-labelledby`) on the outer wrapper of custom modal overlays. Furthermore, ensure an `Escape` key listener (using `useEffect` combined with `window.addEventListener('keydown', ...)`) is properly set up to dismiss the modal, and explicitly manage inner states (like lightboxes or dropdowns) prior to closing the main overlay.
