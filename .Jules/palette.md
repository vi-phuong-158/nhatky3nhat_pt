## 2026-05-30 - Modal accessibility & keyboard navigation
**Learning:** When building custom modals or overlays in React, it is critical to implement `Escape` key event listeners for dismissal. These custom modals also require explicit `role="dialog"`, `aria-modal="true"`, and `aria-label`/`aria-labelledby` attributes to ensure they are properly announced by screen readers. Furthermore, inner material icon spans within action buttons should use `aria-hidden="true"` to prevent redundant screen reader announcements when the button itself already provides an `aria-label`.
**Action:** Ensure that all future custom modal/overlay implementations consistently include standard keyboard dismiss patterns and full ARIA attributes. Hide non-semantic UI icons within labelled buttons from screen readers.
