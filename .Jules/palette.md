## 2025-02-17 - Material Symbol Ligature Accessibility Pattern
**Learning:** In this application, Material Symbols are heavily utilized via the `material-symbols-outlined` class which relies on text ligatures (e.g., `<span class="material-symbols-outlined">close</span>`). When used within icon-only buttons, even if the button has an `aria-label`, screen readers may still independently announce the ligature text (e.g., "close") causing redundant or confusing audio output. Additionally, mouse users lack visual tooltips for these standalone icons.
**Action:** When implementing icon-only buttons utilizing ligature-based icon sets, always apply `aria-hidden="true"` to the inner icon element (the `<span>`) and ensure the parent `<button>` has both a descriptive `aria-label` (for screen readers) and a `title` (for mouse user tooltips).
